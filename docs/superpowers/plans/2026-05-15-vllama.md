# vllama Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build an Ollama-like `vllama` CLI/TUI that manages a local vLLM backend on Linux + NVIDIA systems.

**Architecture:** A Python package provides CLI commands, local state management under `~/.vllama`, server process supervision for `vllm serve`, HTTP chat calls to the vLLM OpenAI-compatible API, and a starter Textual TUI. vLLM remains the inference backend.

**Tech Stack:** Python 3.11+, Typer, Rich, Textual, httpx, pytest.
